# Kontur Jam Dashboard

Дашборд для мониторинга джема по вселенной «К.О.Н.Т.У.Р.» на платформе Dustore

---

## Возможности

- Общая статистика джема — участники, работы, голоса, скачивания
- Лидерборд — баллы и голоса по каждой работе (в приватной сборке)
- Графики активности — голоса и скачивания по дням
- Данные по играм — скачивания, рейтинги, размеры, жанры, движки
- Команды и география — размеры команд, города участников
- Адаптивный дизайн — работает на любых устройствах
